# Phone Station relay

深圳阿里云上的轻量 HTTPS 中继，为一台已配对的手机工位转发 MCP 请求。它不保存业务文件或请求历史；连接用的两枚 bearer 凭据仅放在服务器 root-only 配置中。操作状态只保存在进程内存，服务重启后未完成的操作需要由电脑端标成结果待核实。

## 当前实现

- Go 标准库，无第三方模块。
- 手机用独立 bearer 凭据长轮询，电脑用另一组凭据提交 JSON-RPC 请求。
- 同一台手机一次只派发一个操作；操作 ID 相同且请求体相同时返回同一结果，不同内容返回冲突。手机结果也可安全地用相同内容重传。
- 取消时未派发请求过期，已派发 ping 释放，已派发的其他操作保留结果状态。
- 等待中的请求最多保留 3 分钟；电脑等待响应 3 分钟后得到“结果未知”，应查询原操作 ID，不能自动生成新 ID 重发。
- 完成元数据保留 10 分钟，最多缓存最近 8 个结果正文；较旧操作仍标记已完成，不会重新执行。
- 单请求上限 18 MiB；不写访问日志，不记录请求体或凭据。
- 服务仅通过 TLS 监听；上线时客户端还必须固定验证服务器公钥。

## 本机构建和检查

```sh
go test -race ./...
CGO_ENABLED=0 GOOS=linux GOARCH=amd64 go build -trimpath -o build/phone-relay ./cmd/phone-relay
```

部署位置、证书与凭据文件格式、端口审批和回滚步骤见仓库 [手机工位远程通道运维文档](../../docs/services/phone-station-relay.md)。2026-10-02 已经用户批准部署、放行端口并完成手机配对；后续新增对外端口仍需授权。
