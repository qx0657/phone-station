# 图库截图

日常用法见 [../README.md](../README.md) 的「图库里的截图」。

手机相册里的截图在 `/storage/emulated/0/Pictures/Screenshots`。文件名是 `Screenshot_日期_时间_<界面>.jpg`，界面名用来分组，不能单独当删除依据。同目录的 mp4 是录屏，没点名就不放进截图的删除名单。

判断哪张可以删，看以后还用不用得着图里的信息。正文几乎相同的重复张是另一层，见文末。归类和去重由 `.agents/skills/screenshot-cleanup/scripts/cleanup.py` 做：手机计算指纹，候选原图经 adb 取到电脑临时目录核对，结束后清理。删除不进回收站，用户点名类别或点名按名单删之前不删。点名之后用手机上「手机工位」的 `station_file_delete`，一次一条并携带当前 `targetVersion`，步骤在 `.agents/skills/screenshot-cleanup/SKILL.md`。删掉之后服务会请媒体库再扫这个文件。

下面的张数和体积是 2026-09-29 在荣耀 PGT-AN20 上数的。下次先重新数，不要沿用。

## 可以删

这些类抽过不同日期的几张，内容是齐的：对局、直播、短视频的一帧、打卡状态、当天行情。事实要么已经过期，要么应用里还查得到。

按界面名的子串归类，一条只进最先对上的类。

| 类 | 子串 | 2026-09-29 |
| --- | --- | --- |
| 游戏 | `tmgp_cf_AFMain`、`pubgmhd_Game`、`netease_race_Game` | 343 张，664MB |
| 直播 | `LivePlay`、`LiveSlide`、`LiveDummy`、`TaoLiveVideo`、`FinderShareFeed`、`FinderHomeAffinity`、`FinderLive` | 538 张，681MB |
| 短视频 | `gifmaker_PhotoDetail`、`aweme_DetailActivity`、`aweme_UltraDetail` | 369 张，431MB |
| 打卡页 | `lark_MiniappTabActivity` | 66 张，24MB |
| 行情 | 界面名等于 `com_hexin_plat_android_Hexin` | 90 张，62MB |

五类合计 1406 张，约 1.8GB。当天截图 jpg 共 7334 张，约 6.5GB。录屏 1039 段，约 38GB，没有判断。

直播间里偶发的价目表会跟着直播类一起算进去。那个价格随直播结束失效。短视频类里抽到过参数表和新闻画面，多数仍是播放器里的一帧；新出现的界面先抽样，再决定要不要并进某一类。

## 要留

订单、物流、取件码、账单、缴费回执、车票、合同，以及聊天里的约定、地址和金额。地图上写着要去的地址，或带着支付结果的，也留。

商品详情要留。闲鱼 `DetailActivity`、淘宝 `TTDetailActivity`、京东 `ProductDetailActivity`、抖音 `ProductDetailActivity`，以及拼多多里的商品列表，是比价和参数记录。价格会变，买还是不买还没定时有用。

## 不能整夹删

同一个界面名里，凭据和闲逛会混在一起。

- 微信 `LauncherUI`：聊天正文、聊天列表、别人发来的视频。
- 拼多多 `NewPageActivity`：订单和商品列表。
- 微信小程序 `AppBrandUI*`：地址、取件码、待支付、商品详情。
- 没有界面名的文件：照片、视频、导出的聊天记录。

低方差不是空白。整页几乎纯色的图里出现过缴费金额和对话框。系统的快速 OCR 认不准这台手机上的中文截图，不能拿它划类。

## 重复

先按信息价值划类。用户还要去重时，再找正文几乎相同的张。按修改时间从新到旧比较，每张待删图必须直接匹配最终保留图；时间相同时按文件名排序。相似性不能传递：A 接近 B、B 接近 C，但 A 与 C 已有差异时，不能仅留 C。没有界面名的文件不进重复删除名单。

候选只在同一宽高、同一界面名里找。用原图，不要用缩略图：把状态栏和底部手势条裁掉（竖图大约去掉上方 5% 和下方 3%，横图左右各约 4%），内容缩到宽 800，平均绝对差小于 0.01 才算同一张。差到 0.04 时，套餐剩余次数和钱包余额已经变了。打卡页上只改了一个日期，大约是 0.21。16×16 的感知哈希会把不同的付款金额收成同一张，不能当删除条件。

2026-09-29 按这条规则得到 58 组、61 张可删，约 45MB。其中有隔了几天的同一张回执，正文相同，只差状态栏时间。解码失败的文件跳过，不删。

2026-10-03 在电脑上的合成回归中验证了相似链不会误删、解码失败跳过，以及归档中的路径穿越、符号链接、重复条目、缺图和大小不符会被拒绝。上面的历史张数来自旧版算法，本次没有重新扫描手机，不能作为新版待删张数。候选归档只解出名单内的普通 JPEG，不调用通用解压命令。
