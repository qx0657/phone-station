# 公网中继验收与恢复边界

公网中继服务端源码仍不在本仓库。本篇规定客户端所需的语义，并提供针对隔离实例的可执行验收。通过本机模拟测试不等于正在使用的公网中继已满足这些要求。

## 客户端已经收紧的行为

Mac 19 起，电脑向 `/v1/desktop/call` 提交请求后，网络错误或应答丢失都返回结果未知，不再自动重发，即使仍持有相同 operationId。HTTP 429 只有同时带 `X-Phone-Station-Not-Queued: 1` 才允许有界退避并复用原编号/负载；这个头是服务端对“尚未接收”的承诺。旧中继只返回 429 时直接报告失败，不猜它是否已入队。其他错误不重试。

Mac 中继调用及 Android 60 的 poll/result 禁止自动跟随 HTTP 重定向。手机的结果上报可以重传同一份结果，不重新执行工具。电脑回环通道原有的只读白名单切换仍保留，修改操作应答丢失后只核实。shell 和截图优先用已有后台任务编号查询。

## 服务端必须保证的状态

operationId 由电脑生成，在同一配对的命名空间内唯一，不能仅按 MCP 的 JSON-RPC id 去重。服务端需将配对身份、operationId、原负载摘要和状态原子持久化；先提交接收记录，再确认接收/派发。相同编号相同负载共享结果，相同编号不同负载返回 409，绝不能替换旧请求。

| 原状态 | 收到的事件 | 必须行为 |
| --- | --- | --- |
| 未接收 | 队列已满 | 可返回 429 及 Not-Queued 头；不得留下已接收的请求 |
| 已入队 | 手机 poll | 先持久化为已派发，再返回给手机 |
| 已派发 | 重复 desktop call、重复 poll、电脑取消/断线 | 不再派发同编号；等待原结果或明确返回结果未知 |
| 已完成 | 相同结果重传 | 返回 200 JSON 确认，不再执行；冲突结果返回 409 |
| 已完成 | 相同 desktop call、服务重启 | 返回原结果，不能重新入队 |
| 已派发且未完成 | 服务重启 | 保留未知结果记录，重复调用返回 409/410；不能重派 |
| 结果正文已到保留期 | 相同编号 | 返回已过期/未知，不重新执行 |

手机执行副作用与中继记账之间没有分布式事务，不能承诺 exactly-once。采用“可能没执行、也可能已执行，但结果未知时不重做”的取舍。已入队却未派发可继续派发，但必须能从持久状态确定从未派发过。单靠内存 map、HTTP 重试相同编号或新手机轮询接替旧连接不能保证此语义。

结果正文只短期保留，并限制总字节数；操作回执与正文分开。保留期至少覆盖最长电脑调用及手机结果上报窗口（当前分别 4 分钟、3 分钟）。删除正文后仍需拒绝旧编号；可以保留无正文的 tombstone，或通过服务端发放并持久化的会话 epoch 拒绝旧会话所有编号。不得用一个无边界 TTL 缓存删除全部身份记录后，把旧编号当新操作执行。角色令牌和日志不得包含正文或凭据。

## 隔离实例检查

`./scripts/check-relay.sh <私有配置文件>` 模拟手机和电脑，并执行该配置里的重启命令。必须使用独立的测试实例、空队列、独立数据目录和两枚测试令牌；不能连接真实手机，也不能复用生产实例。检查器只发 `ping` 负载，但它会取走队列项并重启服务，因此不能在生产上使用。

配置保存在仓库外，权限 0600，示例字段如下。令牌使用测试实例实际值，不要将真实配置提交仓库或粘贴进日志：

```json
{
  "isolated": true,
  "endpoint": "https://test-relay.example.com/station",
  "pin": "测试证书的64位SPKI十六进制摘要",
  "phoneToken": "独立的手机测试令牌",
  "desktopToken": "独立的电脑测试令牌",
  "restartCommand": ["/absolute/path/restart-isolated-relay.sh"]
}
```

重启脚本在原数据目录重启测试服务，25 秒内完成且服务就绪后才退出。用参数数组直接执行，不经 shell 拼接；输出不会写入测试日志。检查器最多运行 75 秒，严格核实固定 SPKI，不跟随重定向。

覆盖角色隔离、相同编号正在执行/完成后的去重、不同负载冲突、结果重复/冲突、电脑取消、已完成结果跨重启保留，以及已派发未完成操作跨重启不重放。超过正文保留期、队列满、磁盘写满、多个手机竞争和进程在 fsync 前后被强杀仍需服务端源码侧的故障注入测试；这套短时黑盒验收不能替代那些测试。

`./scripts/check.sh` 只运行内存测试实例验证检查器本身：正常回执保留应通过，模拟重启丢失回执必须失败。真实公网验收由 `check-relay.sh` 单独运行，配置缺失会失败，不会静默跳过。目前没有取得或运行真实中继配置，也没有替换现网服务。
