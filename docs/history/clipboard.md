## 验证

2026-10-03 的实机根因是 PGT-AN20 电脑通道在线，但 Shizuku 服务未运行。原来读取手机剪贴板先失败，Mac 未能进入交换，手机端没有成功交换心跳；界面把它写成「Mac 未连接」，又把全部读取错误统一写成启动/授权提示。首页的权限汇总同时忽略 Shizuku，导致阻塞原因没有提前出现。

49 版与 Mac 9 的完整构建通过，新增 `HealthStatusTest`、`DeviceHealthSessionTest` 和剪贴板 session 回归覆盖权限阻塞、服务失败、功能之间的依赖、诊断恢复、只读诊断和迟到响应；原有同步冲突与短暂断线恢复测试通过。手机通过已有 adb 保留数据升级；Mac 安装代码、随包 APK 和签名已核对，旧 App 留在忽略的备份目录。更新后实际状态先返回 `transportConnected: true`、`ready: false` 和「Shizuku 未启动」；随后 Shizuku 已运行且授权，客户端自动建立共享会话，状态恢复为 `ready: true`、`macOnline: true`，Shizuku 阻塞提示清除。本次没有主动撤销授权、停止 Shizuku或写测试剪贴板。

首页的缺失依赖已通过 PGT-AN20 浅色实机画面核对，恢复后的首页检查了浅色和深色 1.3 倍字号，并恢复原来的浅色 1.0 倍设置。Mac 首页和共享页的阻塞布局使用无真实剪贴板的 fixture 做浅色/深色原生渲染，不代表已安装 popover 的完整点击验证。评审图在忽略的 `.impeccable/review/`，导航命令通过实际 Activity 焦点核对。最终只读检查为 `health.issues: []`，剪贴板和手机通知的 Mac 会话均在线。

电脑测试 `ClipboardStateTest` 覆盖首次连接、Mac 复制、手机同时复制优先、重复请求、手动模式、离线过期、敏感数据不序列化、重启基线与相同文字重新复制。`ClipboardSyncPolicyTest` 覆盖手机复制到 Mac、请求途中的本机新复制、回传抑制、敏感本机剪贴板、短暂切换恢复、未知结果不重放、服务重启和恢复窗口过期。`ClipboardSessionTest` 使用模拟请求与剪贴板，覆盖等待时连续复制、核对期间再次复制、只读核对后恢复、状态提示，以及切换期间手机到 Mac 的恢复。完整构建由 `scripts/build-mac-app.sh` 执行。

2026-10-02 的恢复优化已安装到 Android 44 与 Mac 0.1.0 (4)。统一全量构建和上述剪贴板测试通过；远程升级原任务返回 `verified: true`、`completed: true`，实际安装的代码与资源均与构建一致。经远程只读核对，手机已提供 `refresh`、`resume` 与会话标识，共享和自动同步保持开启，Mac 在线且无剪贴板错误，原有 Shizuku 授权保留。本次切换中连续复制的回归使用模拟请求验证，实机检查使用只读状态核对，未主动切换 Wi-Fi 或写入测试文字。

2026-10-02，荣耀 PGT-AN20（Android 15 / MagicOS 9）与 Mac 完成实测：

- 本地无线 adb 与远程中继分别运行同一组原生 Mac 客户端测试，双向自动同步、手动复制、预览、换行/中文/emoji、敏感 Mac 内容跳过、回传抑制、相同手机文字重新复制与断线重连均通过。远程测试期间只移除 adb MCP 转发，保留无线调试；网关明确为 remote、localOnline=false。
- 后台读取通过专用 Shizuku UserService；首次按 AOSP 签名调用失败，发现荣耀接口差异后修正。读取与写后核对均通过，应用没有取得前台焦点也可读取。
- 测试保存并恢复两端原剪贴板内容，不输出真实内容。测试后的空手机剪贴板恢复为空文字；未创建历史或内容文件。
- Android 构建、Mac 完整构建、新增同步/签名测试与 MCP HTTP 路由测试通过。

实测没有重启手机或主动停止 Shizuku；相应不可用状态由状态检查和错误路径处理。没有验证其他机型、Android 多用户或图片/文件同步。

上述实测结束时，安装版本为 Android 42 与 Mac 0.1.0 (3)，两端已启动并开启共享和自动双向同步。Mac 位于 `/Applications/手机工位.app`，签名验证通过，主程序与随包 APK 均与当次实测构建一致；远程升级返回 `completed: true`。原有中继配对与 Shizuku 授权保留。

两端界面使用原生组件：Mac 检查浅色与深色 NSHostingView 渲染，手机检查实际浅色、深色和 1.3 字号页面。PGT-AN20 写入 `font_scale` 后，旧 Activity 的文字可能不立即变化；验证字号需要重建 Activity，再核对实际字形变大，不能只看设置值。截图位于忽略的 `.impeccable/review/`；Mac 截图原生控件处于非活动外观，实际操作已由客户端实测覆盖。
