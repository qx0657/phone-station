# 应用显示语言

`en.json` 是 Android 和 Mac 共用的英文显示词典，键为现有中文文案。两端默认跟随系统，中文系统使用中文，其他语言回退英文，也可在各自设置中手动选择。Android 打包为 `assets/ui-en.json`，Mac 打包为 `Contents/Resources/ui-en.json`；应用名称与系统权限说明另用原生本地化资源。

连接与权限模型继续返回原来的规范值，界面在显示时翻译，不用译文做状态判断。词典支持完整文案、`{0}` 起的参数模板，以及由已知文案拼接的状态；含未知中文的消息原样保留，避免局部替换。新增文案优先添加完整句子或参数模板，参数前后不要依赖中文词序。两端替换参数时保留原值，包括参数中的花括号。

文件名、命令正文、通知内容、应用名和实际手机路径保留原文，不送入通用文案翻译。Android 普通通知的明暗颜色跟随系统通知底色，以保证对比度；应用页面跟随本端主题选择。

`scripts/check.sh` 包含词典重复键、参数对应、路径保留与两端显示回归；`lib/android/build.sh` 和 `scripts/build-mac-app.sh` 验证实际打包。真机点击、字号与系统生命周期仍按 [界面验收](../../docs/validation.md#界面改动验收) 单独确认。
